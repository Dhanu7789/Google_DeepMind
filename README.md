# ⚡ AI Website Generator

An AI-powered website builder that generates complete frontend websites using OpenAI.

Users can describe a website idea in plain English, and the app automatically generates:

- HTML
- CSS
- JavaScript
- Live Preview
- Downloadable ZIP files

---

# 🚀 Features

✅ AI Website Generation  
✅ Live Website Preview  
✅ Copy HTML/CSS/JS Code  
✅ Download ZIP Project  
✅ Modern Glassmorphism UI

✅ OpenAI API Integration

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Dhanu7789/Google_DeepMind.git
```

---

## 2️⃣ Move Into Project

```bash
cd Google_DeepMind
```

---

# 🔥 Backend Setup

## 3️⃣ Install Dependencies

```bash
cd backend

npm install
```

---

## 4️⃣ Create `.env`

Create a `.env` file inside backend folder:

```env
OPENAI_API_KEY=your_openai_api_key
```

---

## 5️⃣ Start Backend Server

```bash
node server.js
```

Server runs on:

```bash
http://localhost:5000
```

---

# 🎨 Frontend Setup

Open frontend folder and run using Live Server.

OR

```bash
npx serve .
```

Frontend runs on:

```bash
http://127.0.0.1:5500
```

---

# 💡 How It Works

1. User enters website prompt
2. Frontend sends request to Express backend
3. Backend calls OpenAI API
4. AI generates:
   - HTML
   - CSS
   - JS
5. Frontend:
   - Displays code
   - Shows live preview
   - Enables ZIP download
